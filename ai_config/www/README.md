# Панель управления приставками (docroot тестового веб-сервера)

Запуск сервера (на этом ПК):

```powershell
php -S 192.168.1.100:8088 -t ai_config/www
```

Авторизация — Basic Auth на веб-сервере; логин и пароль задаются в конфигурации
сервера (в самом PHP только CSRF-защита).

## Файлы

| Файл | Назначение |
|------|-----------|
| `index.php` | Панель: таблица устройств, ссылка + тип, комментарий (расположение), статус, кнопки |
| `logs.php` | Просмотр логов: список файлов и хвост лога (автообновление) |
| `lib.php` | Хранилище устройств, генерация `settings.json`, разбор `HEARTBEAT`, ping, запуск py |
| `devices.json` | Список устройств — **источник истины панели** |
| `settings.json` | **Единый конфиг** — генерируется из `devices.json`; его отдаёт приставкам веб-сервер и заливает `tools/deploy_services.py` |
| `log.php` | Приёмник логов + **ротация** (2 МБ на файл, 3 архива `.bak`, внутри самого скрипта) |
| `mag_logs/` | Принятые логи: `<MAC через дефис>.log` |
| `test.html` | Мини-проверка «приставка → сервер» |

## Кнопки в панели

| Кнопка | Что делает |
|--------|-----------|
| **Сохранить** | пишет `devices.json` и перегенерирует `settings.json` |
| **Перезагрузить** | `tools/mag_ctl.py --hosts <ip> --reboot` |
| **Обновить services** | `tools/deploy_services.py --hosts <ip>` |
| **Проверить** | `tools/check_playback.py --hosts <ip>` (играет ли поток) |
| **Ping** | нативный `ping` (Windows/Linux) |
| **Mute / Вкл. звук** | флаг `mute` в `settings.json`; портал применит в течение ~1 мин |
| **Логи** | открывает `logs.php?mac=...` |

### Групповые кнопки (вверху панели)

| Кнопка | Что делает |
|--------|-----------|
| **Ping всех** | ping всех устройств, сводка доступности |
| **Проверить всех** | `tools/check_playback.py` по всем устройствам |
| **Обновить на всех** | `tools/deploy_services.py` по всем (с подтверждением) |
| **Перезагрузить всех** | `tools/mag_ctl.py --reboot` по всем (с подтверждением) |

## Статус устройства

Считается из последней строки `HEARTBEAT` в логе:

- **работает** — свежий heartbeat (≤ 180 c) и `playing=yes`;
- **не играет** — свежий heartbeat, но `playing=no`;
- **нет связи** — heartbeat устарел (> 180 c);
- **нет данных** — heartbeat ещё не приходил (портал без поддержки heartbeat).

## Настройки (`lib.php`)

- `STREAM_TYPES` — список типов потоков в выпадающем списке.
- `PYTHON_BIN` — интерпретатор Python (по умолчанию `python`).
- Пути к `tools/*.py` берутся из корня репозитория.
